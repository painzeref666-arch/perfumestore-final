EXOUSIA & CO. GLOBAL THEME CONTRAST PATCH

This patch updates src/styles/index.css with conservative site-wide contrast improvements:
- Muted text utility colors in both themes
- Placeholder and form-control readability
- Dropdown option colors
- Focus-visible outlines
- Dark text on selected champagne-gold primary button classes

It does not intentionally modify business logic, Supabase, checkout, order processing, inventory, booking, or authentication.

Please test representative pages in both Light and Dark modes before deploying. CSS overrides may need refinement for components with intentionally unusual color combinations.
Build verification was not performed as part of this patch.
